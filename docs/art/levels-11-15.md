Полноразмерные `public/assets/level-11.webp` … `level-15.webp` кодированы WebP без потерь, размер 848×1264; ImageMagick `compare -metric AE` показал 0 отличающихся пикселей у каждой пары PNG/WebP. Миниатюры `level-11-thumb.webp` … `level-15-thumb.webp` пропорционально уменьшены до 240×358 без обрезки, кодированы WebP с качеством 83 и без метаданных. Исходные PNG находятся вне production-сборки.

Для 16 деталей используется генератор связных масок с 4×4 опорными точками, для 17 и 18 — 4×5 с пропущенными точками, равномерно распределёнными между рядами. Каждый пиксель исходной картины принадлежит ровно одному фрагменту. Конфигурация `src/levels.ts` допускает добавление уровней 16–25 без смены версии или ключа сохранения.
