Полноразмерные `public/assets/level-21.webp` … `level-25.webp` кодированы WebP без потерь в исходном разрешении 848×1264. ImageMagick `compare -metric AE` показал 0 отличающихся декодированных пикселей у каждой пары оригинал/WebP. Для уровня 24 эталоном служил декодированный исходный JPG; преобразование не может восстановить данные, отсутствующие в JPG. Миниатюры `level-21-thumb.webp` … `level-25-thumb.webp` пропорционально уменьшены до 240×358 без обрезки, кодированы WebP с качеством 83. Художественное содержание и пропорции не изменялись. Исходники находятся вне production-сборки.

Для 21 и 22 деталей используются связные маски сетки 4×6 с равномерно распределёнными незанятыми опорными точками. Уровень 25 временно использует существующие 14 деталей сетки 4×4. Ключ и версия прогресса не изменялись.
