# Коллекция: уровни 1–5

Источник: предоставленный пользователем `levels_01-05.zip`. Его ранее извлечённые PNG перенесены без изменения байтов в `docs/art/source/levels-01-05/`, вне production-сборки. Миниатюры сохраняют полный кадр и пропорции; они загружаются для сеток выбора и галереи. Полноразмерная картина загружается при запуске пазла или открытии картины в галерее.
