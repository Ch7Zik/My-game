# Предрелизный аудит «Пазлы и картинки»

Дата: 2026-10-25. Основа: `main` после объединения PR #34, #35, #36 (`7241708`). Проверка выполнена в Chromium Linux с эмуляцией размеров телефона; физический телефон и окружение Яндекс Игр не использовались.

## Подтверждённые изменения

- Исправлен базовый путь обычной production-сборки: `vite build --base=./`. Ранее `dist/index.html` ссылался на `/assets/...`, что не работает при размещении ZIP под вложенным адресом. GitHub Pages продолжает собираться отдельно с `--base=/My-game/`.
- Добавлен smoke-тест релизной сборки, размещённой под `/nested/game/`, с реальным открытием меню и первого пазла в Chromium. В workflow GitHub Pages тот же тест запускается после сборки с путём `/My-game/`.
- Добавлен браузерный прогон ключевых экранов на шести размерах и снимки в `docs/screenshots/final-release-audit/`.

## Произведения

В `src/levels.ts` ровно 25 уровней, номера 1–25 идут подряд, уровень 25 содержит 14 деталей. Для каждого уровня существуют полноразмерный WebP и миниатюра. SHA-256 файлов в `docs/art/source/` совпали с ранее записанными контрольными суммами в `docs/art/levels-*.md` (25/25). Команда `magick compare -metric AE` дала `0` для каждой пары источник/WebP (25/25), включая сравнение JPG для уровня 24. Это сверка с сохранёнными исходниками репозитория; независимая повторная сверка с пользовательскими ZIP в этом аудите не выполнялась. Все исходники имеют 848×1264, полноразмерные WebP также 848×1264, миниатюры 240×358. Файлы картин не менялись.

## Релизный архив

После `npm run build` архив `/tmp/my-game-final-audit.zip` содержит 79 файлов, 49 619 004 байта (47,32 МиБ); распакованный `dist/` — 51 214 144 байта (48,84 МиБ). `index.html` находится в корне. Контроль CRC `ZipFile.testzip()` не обнаружил ошибок. Все имена ASCII; исходники, тесты и `docs/` в `dist/` отсутствуют. Это меньше заданного пользователем лимита 100 МБ. Актуальный лимит платформы по официальной документации независимо не подтверждён из-за блокировки доступа к сайту Яндекса. GitHub Pages и ZIP имеют разные базовые пути.

Опубликованный `https://ch7zik.github.io/My-game/` проверить не удалось: запрос `curl` получил HTTP 403 на CONNECT от сетевого прокси этой среды, до сайта запрос не дошёл. Конфигурация workflow использует `build:pages`, загружает `dist` и запускается на `main`; доступность фактического деплоя и настройки Pages остаются **NOT VERIFIED**. Для проверки после объединения владельцу следует открыть `Settings → Pages → Build and deployment` (источник `GitHub Actions`), затем вкладку `Actions → Publish test game to GitHub Pages` и сам адрес сайта в обычном браузере.

## Риски и ограничения

- **BLOCKER:** В проекте отсутствует SDK Яндекс Игр и вызовы `LoadingAPI.ready()` и `GameplayAPI.start()/stop()`. Рекламных вызовов также нет. Интеграцию с окружением Яндекса и официальную документацию в этой среде проверить не удалось: доступ к `yandex.ru` отклонён сетевым прокси (HTTP 403). До платформенной интеграции и теста в её среде готовность к публикации подтвердить нельзя.
- **MINOR / гипотеза:** Отображение подписей в карточках выбора уровня и галереи на 320×568 местами мелкое (10–12 CSS px). Нужно оценить на физическом телефоне; неудобство в этой эмуляции и по отзывам двух игроков не подтверждено. Существенная перестройка карточек в рамках аудита не проводилась.
- **MINOR:** Игра использует поле и растеризацию деталей в отношении 2:3, тогда как исходные картины имеют отношение 848:1264. Разница около 0,63% по ширине. Тексты и содержимое картин не менялись. Исправление повлияло бы на геометрию всех пазлов и требует отдельного согласования.
- Встроенный WebGL на эмуляторе Chromium использует SwiftShader. FPS, время загрузки при медленной сети, потребление памяти, блокировка экрана и реальное поведение SDK не измерялись. Не следует считать их проверенными.

Вердикт для Яндекс Игр: **NOT READY** из-за отсутствия SDK и платформенной проверки. Браузерная версия отдельно работоспособна по выполненным сценариям.

Внешние замечания о неудобстве первого уровня и существенном отличии кнопки «Далее» от остального интерфейса не подтвердились при просмотре реальных кадров и браузерном взаимодействии. Разработчик ранее лично прошёл первый уровень без неудобств; ещё один игрок не сообщил о проблемах. Поэтому форму и количество деталей, управление, подсказки и стиль кнопки не меняли. Подтверждённая ошибка этого аудита — абсолютный путь `/assets/` в обычной ZIP-сборке; исправлена и проверена тестом под вложенным URL. Других подтверждённых BLOCKER/MAJOR ошибок браузерной игры в проведённых сценариях нет.
