# Alchemist menu reference

`approved-concept.png` is the approved menu from the supplied `Desktop.zip`.
`clean-background.png` is the separate, text-free illustration from the same archive.

The game loads `public/assets/menu-alchemist.webp`, encoded from the clean illustration at its original 938×1677 aspect ratio. The logo and three button sprites are separate interface assets derived from the approved concept; the main button's center was cleared so its caption can reflect saved progress. The music and settings icons are drawn by Phaser. At runtime the background uses cover scaling, while interface elements follow the vertical reference positions.

`docs/screenshots/alchemist-menu/compare-390x844.png` places the approved concept next to an actual 390×844 Chromium capture.
