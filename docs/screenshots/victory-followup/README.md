# Проверка экрана победы

Снимки сделаны из работающей игры в Chromium после обычного перетаскивания и фиксации всех четырёх деталей первого уровня. Тест не вызывает `finish()` напрямую. Сценарий также нажимает «Далее», перезагружает страницу и проверяет сохранённый результат.

| Размер окна | Скриншот |
| --- | --- |
| 360×640 | [victory-360x640.jpg](victory-360x640.jpg) |
| 390×844 | [victory-390x844.jpg](victory-390x844.jpg) |
| 430×932 | [victory-430x932.jpg](victory-430x932.jpg) |
| 1920×1080 | [victory-1920x1080.jpg](victory-1920x1080.jpg) |

Автоматический сценарий: `npm run test:browser`. Для записи новых снимков задайте `VICTORY_SCREENSHOT_DIR` абсолютным путём к каталогу. Параметры прохождения сохранены в [browser-results.json](browser-results.json).

На опубликованной игре временная надпись `Победа-2 · <хеш>` у нижнего края показывает идентификатор загруженного JS-кода. После объединения PR сравните хеш с коммитом, указанным в успешном workflow Pages. Для диагностики путь последнего завершения уровня записывается в `localStorage` по ключу `mystic-puzzles-victory-log-v1` (до 20 событий); доступ к хранилищу не влияет на игру. Открытый PR сам по себе не обновляет GitHub Pages.

Снимки сняты в Chromium. На физическом iPhone исправление ещё требует проверки после публикации; Safari/WebKit в этой среде недоступен.
