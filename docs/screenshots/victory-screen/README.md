## Сверка с присланными снимками iPhone

На пользовательском снимке после победы полностью видна картина, но нет времени, звёзд и кнопки; «Картина собрана!» пересекает орнамент шапки. На снимке [360×640 после](after/victory-360x640.jpg) картина находится над отдельной компактной областью результатов, где одновременно видны заголовок, время, три звезды и кнопка. Картину не накрывает окно результатов. Это сравнение браузерного результата с примером дефекта, а не подтверждение работы на физическом iPhone.

Найдены две причины в текущем коде. Во-первых, на узком экране вся высота почти полностью отдавалась картине, место резервировалось только для кнопки, а время и звёзды помещались в тесную орнаментальную шапку. Строка под картиной дополнительно скрывалась при недостатке места. Новая компоновка выделяет область результатов **до** расчёта размера завершённой картины и учитывает верхний и нижний безопасные отступы. Во-вторых, после изменения размеров окна Phaser обновлял логическую сцену, но canvas мог оставаться уменьшенным по старым размерам; фактическая зона касания кнопки тогда не совпадала с её изображением. Теперь после `setGameSize` обновляются размеры родительской области и canvas через `scale.refresh()`. Пазл до победы использует прежнюю геометрию.

Автоматический сценарий `npm run test:browser` проверяет фактические границы текста и элементов, отсутствие пересечений, пиксели золота в заголовке, времени, каждой звезде и кнопке, сохранение результата, переход «Далее», повторное прохождение, изменение размера и безопасные отступы.
