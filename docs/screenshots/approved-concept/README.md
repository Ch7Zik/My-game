# Утверждённый концепт: реальные кадры игры

«До» — кадры работающей версии из PR #8 (перенесены из `docs/screenshots/ui-polish/after`). «После» — кадры этого PR из запущенной игры в Chromium. Для выбора уровней и галереи использован тестовый прогресс с двумя пройденными уровнями; для кадров «после» добавлены тестовые записи 3 и 2 звезды. Победа показана через штатный метод завершения сцены после подготовки настоящих фрагментов; время 01:24 задано для демонстрации таймера. Это скриншоты игры, а не макеты. Настоящий iPhone для проверки не использовался.

Размер поля измерен в логических пикселях Phaser через `gameLayout` до и после изменения. Соотношение сторон 2:3 сохранено, геометрия масок и правила фиксации не менялись.

На длинных телефонах поле уже почти упиралось в ширину экрана. Дополнительный рост без обрезки иллюстрации ограничен её утверждённым форматом 2:3. Измерения нового поля и отсутствие горизонтальной прокрутки также записаны в [отчёте Chromium](after/measurements.json).

Утверждённая композиция показала больше пяти уровней. Игра сохраняет существующие пять; дополнительные карточки и уровни в этом PR не создавались. Миниатюры карточек кадрируют исходные иллюстрации, а сама игра и просмотр галереи показывают их целиком. На ПК оставлен существующий образец картины рядом с полем; на телефоне отдельного образца и нижней панели нет.
