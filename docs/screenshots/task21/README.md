# Task 21: experimental twelve-piece library

The sixth painting, `public/assets/enchanted-library.webp`, was generated for this project with OpenAI Image Generation from a text description of a warm, moonlit fantasy library. No third-party stock illustration was used. The 1024×1536 source was encoded as WebP for the game; the five existing artworks are untouched.

The new masks use one staggered 3×4 set of twelve sites and a smooth shared warp. The geometry of levels 1–5 remains on its original code path. At 360×640 the smallest loose piece is about 83 px along its shorter bounding dimension. All twelve masks are connected and pass the existing shape checks at 240×360, 720×1080 and 840×1260. Start positions are deliberately displaced from their homes; every piece exposes a large area to touch without another piece on top. The star thresholds for twelve pieces are 6 minutes for three stars and 12 minutes for two; earlier thresholds are unchanged.

The PNGs here are screenshots of the running Phaser game, captured during a full mouse or emulated touch playthrough. For every tested viewport (360×640, 375×667, 390×844, 393×852, 430×932 and 1920×1080), `levels-*` shows the sixth card, `start-*` shows all pieces, `partial-*` shows the half-built picture, `assembled-art-*` is a crop of the finished painting from the game canvas, and `victory-*` shows the existing result screen. `gallery-390x844.png` and `gallery-1920x1080.png` show the unlocked painting. `replay-victory-390x844.png` follows a second normal playthrough.

The browser test selects each visible detail by its true opaque mask and checks that touch selects the intended piece without a start jump. It also verifies the hint, completion, final-level button, gallery viewing, saved result after reload and replay. These checks run in Chromium. A physical iPhone and Safari were not available; feel and precision on a real device still require manual confirmation before expanding the collection.
