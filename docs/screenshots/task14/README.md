# Задание 14: игровой экран и отдельная победа

Все JPG в `before/` и `after/` — скриншоты реально запущенной игры в Chromium. Уровень 1 собран последовательными действиями мыши или CDP touch; экран победы не вызывался напрямую. Размер указан в имени файла. `before/` снят с дерева `main` после PR #13 (SHA дерева `1847090f8c168cad3ae7f317dbe66c96eea2522f`). Снимок победы 430×932 скопирован из результатов PR #13, собранных с того же дерева. Остальные снимки `before/` сняты повторно из чистого архива этого дерева.

Игровая картина не уменьшена: `gameLayout()` и координаты фрагментов не изменились. На 360×640 область по-прежнему 352×528 CSS px; на 390×844 — 386×579 CSS px. Шапка теперь отделяет уровень и время от названия, а победа имеет собственную компоновку и отдельную рамку завершённой картины.

В утверждённом концепте присутствуют тёмная сказочная палитра, крупная картина, золотые звёзды и выразительная кнопка — это воспроизведено. Оставшиеся отличия: рамка и орнамент экрана победы легче и проще, а пять игровых иллюстраций сохранены без замены; концепт изображает иные сюжеты. Исходный файл концепта в рабочем каталоге недоступен, поэтому точное пиксельное сравнение не выполнялось. Эти снимки сняты в Chromium, не на физическом iPhone.
