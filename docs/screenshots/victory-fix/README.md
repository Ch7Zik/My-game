# Проверка экрана победы

Снимки получены из работающей игры в Chromium. Каждый кадр победы сделан после настоящего прохождения первого уровня: четыре фрагмента перетащены событиями указателя/касания в их позиции. `before` — объединённая `main` до исправления; `after` — эта ветка. Это эмуляция касаний в браузере, а не проверка на физическом iPhone.

| Размер | До: результат | После: картина до результатов | После: результат |
| --- | --- | --- | --- |

| 390×844 | [до](before/victory-results-390x844.jpg) | [картина](after/victory-picture-390x844.jpg) | [результат](after/victory-results-390x844.jpg) |
| 430×932 | [до](before/victory-results-430x932.jpg) | [картина](after/victory-picture-430x932.jpg) | [результат](after/victory-results-430x932.jpg) |

Для стабильного кадра картины до результатов на 430×932 и 1920×1080 диагностически задержан только переход к результатам на несколько секунд в запущенной игре. Обычный срок показа в исходном коде — 1,8 с. Скриншоты не являются макетами.

Данные прохождения и ошибок загрузки: [до](before/browser-flow.json), [после](after/browser-flow.json). Дополнительная браузерная проверка в [verification.json](verification.json) включает прерывание завершающих анимаций, кнопку «Далее», повторное прохождение с улучшением результата, сохранение после перезагрузки и проверку длинного заголовка.
