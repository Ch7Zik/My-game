# Задание 17: визуальная проверка

Снимки сделаны из **работающей игры в Chromium** через Playwright. Папка `before` снята с `main` на коммите `24769e7` после PR #16. Папка `after` снята после исправлений. Это изображения canvas без панелей браузера. Они не являются снимками физического iPhone или Safari.

Для каждого экрана есть кадры `before/ИМЯ-РАЗМЕР.jpg` и `after/ИМЯ-РАЗМЕР.jpg`, а также `compare-ИМЯ-РАЗМЕР.jpg` (слева до, справа после) для 390×844 и 1920×1080. Итоговые мобильные кадры дополнительно сняты при 360×640, 375×667, 393×852 и 430×932:

| Экран | Вывод аудита |
| --- | --- |
| `menu` | Логотип и кнопки уже центрированы; изменений не требуется. |
| `levels` | Заголовок был сдвинут вправо на 10 px. Теперь центрирован. Карточки сохраняют исходные размеры; при 25 уровнях прокручиваются целыми рядами. |
| `gallery` | Тот же сдвиг заголовка на 10 px исправлен. Двухколоночная сетка, скрытые картины и звёзды сохранены. |
| `view` | Заголовок, крупная картина, результат и кнопка закрытия проверены; изменений не требуется. |
| `game` | Слово «УРОВЕНЬ» и цифры имели разные размеры текстовых объектов и независимые метрики высоты. Теперь это один объект с общей базовой линией и тенью. Картина и фрагменты не менялись. |
| `victory` | Заголовок, звёзды, время и кнопка проверены после обычной сборки пазла; изменений композиции не требуется. |

Фрагменты `detail-level-01-*` и `detail-level-25-*` показывают надпись крупно. Номера 8, 10, 11, 19 и 25 тестируются **только в шапке** через временную замену номера при работающей сцене; новые уровни не добавлены.

Браузерный сценарий `tests/browser-task17.mjs` проходит меню → выбор → галерею → просмотр → игру → победу реальными касаниями/мышью, нажимает «Далее», меняет размер окна и проверяет сохранённый результат после перезагрузки. Вручную на физическом iPhone остаётся сверить оптическое выравнивание шрифта Georgia в Safari, safe-area и реакцию касаний.
