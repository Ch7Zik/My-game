# Мистические пазлы

Мобильная HTML5 игра на Phaser 3, TypeScript и Vite. Первый уровень собирает исходную иллюстрацию ночного дома у озера из восьми крупных фигурных фрагментов. Детали свободно перетаскиваются в основной игровой области, примагничиваются к своему месту, а после установки последней плавно уступают место цельной картине без швов. Переход выполняется только кнопкой.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Устройство

- `src/geometry.ts` — подготовленный шаблон из восьми плавных асимметричных областей и измерение качества растровых масок. Каждому пикселю назначается ровно один фрагмент. Для других размеров есть экспериментальный плавный генератор.
- `src/layout.ts` — размеры картины и разнесённые стартовые позиции для телефона, планшета и ПК.
- `src/main.ts` — меню, HUD, перетаскивание, подсказка, магнит, звук и завершение.
- `public/assets/moonlit-cottage.png` — исходная иллюстрация без обрезки и искажения пропорций.
- `tools/generator.html` — локальная утилита для экспорта PNG атласа и JSON с координатами и метриками формы. Открывается через Vite по `/tools/generator.html`.
- `docs/screenshots/` — реальные кадры Chromium после переработки; `docs/screenshots/before/` — кадры до неё.

Шаблон первого уровня специально настроен для иллюстрации 2:3. Утилита допускает другие сетки как экспериментальный режим. Для будущих уровней потребуется отдельная художественная проверка каждой конфигурации. Новых уровней, экономики и рекламы здесь нет.
