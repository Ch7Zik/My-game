# Мистические пазлы

Мобильная HTML5 игра на Phaser 3, TypeScript и Vite. Пять тестовых уровней собираются из 4/4/6/6/8 крупных фигурных фрагментов. Детали свободно перетаскиваются и примагничиваются к своим местам. После последней детали все швы исчезают, а перед игроком остаётся исходная иллюстрация. Переход к следующей картине происходит только по кнопке.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Тест на телефоне через GitHub Pages

После объединения PR с настройкой Pages откройте в репозитории **Settings → Pages → Source → GitHub Actions**. Дождитесь успешного workflow **Publish test game to GitHub Pages**. Затем откройте на Android или iPhone адрес https://ch7zik.github.io/My-game/ в браузере. Кнопкой «Играть» запускается следующий доступный уровень; завершения сохраняются в браузере этого устройства.

Для Pages workflow выполняет `npm run build:pages` с базовым путём `/My-game/`. Обычная команда `npm run build` по-прежнему собирает игру для запуска из корня ZIP Яндекс Игр.

## Звук и качество рендера

После первого касания игра запускает плейлист из шести атмосферных композиций. Музыка продолжается при переходах между экранами, плавно меняет громкость между треками и приглушается на время победных колокольчиков. Звуковые эффекты есть только у успешной установки детали и завершения картины; обычные нажатия и перетаскивание беззвучны. В главном меню кнопка динамика открывает отдельные переключатели «Музыка» и «Эффекты». Выбор хранится в `localStorage`; при скрытой странице воспроизведение приостанавливается. Музыка поставляется в MP3, эффекты — в Ogg Vorbis и AAC/M4A для Safari. [Источники аудио и условия использования](public/audio/README.md).

[Аудит разрешений, сжатия и масштабирования](docs/task5-image-audit.md) содержит размеры всех семи иллюстраций, фактические размеры вывода и описание исправлений. [Скриншоты задачи №5](docs/screenshots/task5/) сняты в Chromium с реальной игры.

[Сравнение интерфейса до и после визуальной полировки](docs/screenshots/ui-polish/README.md) содержит реальные кадры меню, выбора уровней, галереи, игры и победы для телефона и ПК.

[Реализация утверждённого концепта](docs/screenshots/approved-concept/README.md) показывает реальные кадры до и после и замеры площади игрового поля.

## Время и звёзды

Таймер считает время сборки вверх и приостанавливается, когда вкладка скрыта. После победы результат оценивается от одной до трёх звёзд. Начальные пороги для 4, 6 и 8 деталей находятся в `src/results.ts`; они не ограничивают время и не влияют на открытие следующего уровня. Лучшее время и максимальное число звёзд каждого уровня хранятся отдельно от прежнего прогресса. Повторная сборка может улучшить результат.

## Устройство

- `src/levels.ts` — конфигурация пяти уровней: иллюстрация, число фрагментов, геометрия, стартовые позиции, название и фраза.
- `src/geometry.ts` — общая растровая маска с художественными профилями для 4, 6 и 8 деталей. Каждому пикселю соответствует ровно один фрагмент. Контролируются связность, площадь, ширина, вытянутость и острота формы.
- `src/layout.ts` — пропорциональная картина и стартовые позиции на телефоне, планшете и ПК.
- `src/progress.ts` — прежнее сохранение версии 1 в `localStorage`: пройденные уровни и последний выбранный уровень. Оно не сбрасывается при обновлении.
- `src/results.ts` — отдельное сохранение лучшего времени и заработанных звёзд, а также настраиваемые пороги. При недоступном хранилище игра остаётся рабочей, но результаты не переживают перезагрузку.
- `src/main.ts` — меню, выбор уровней, галерея, общая игровая механика, подсказка, магнит, звук и завершение.
- `tools/generator.html` — локальная утилита для экспорта PNG атласа и JSON с координатами и метриками формы. Открывается через Vite по `/tools/generator.html`.
- `docs/screenshots/task4/` — реальные снимки этой версии в Chromium. Старое меню для сравнения находится в `docs/screenshots/01-menu-390x844.png` и `docs/screenshots/05-game-start-360x640.png`.

Игра загружает все пять изображений при запуске и затем работает без сети. Рекламы, экономики и авторизации Яндекса в этой версии нет. Уровни после пятого пока не созданы.
