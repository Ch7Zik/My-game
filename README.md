# Мистические пазлы

Мобильная HTML5 игра на Phaser 3, TypeScript и Vite. Пять тестовых уровней собираются из 4/4/6/6/8 крупных фигурных фрагментов. Детали свободно перетаскиваются и примагничиваются к своим местам. После последней детали все швы исчезают, а перед игроком остаётся исходная иллюстрация. Переход к следующей картине происходит только по кнопке.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Уровни и изображения

| Уровень | Фрагменты | Сцена | Файл |
| --- | ---: | --- | --- |
| 1 | 4 | Домик у озера | `public/assets/moonlit-cottage.png` |
| 2 | 4 | Лесная избушка | `public/assets/firefly-cabin.webp` |
| 3 | 6 | Лунный маяк | `public/assets/moonlit-lighthouse.webp` |
| 4 | 6 | Мост через реку | `public/assets/forest-bridge.webp` |
| 5 | 8 | Замок среди гор | `public/assets/moonlit-castle.webp` |

Иллюстрация первого уровня создана для первого задания. Четыре новых изображения и два фона меню (`menu-forest.webp` для телефона и `menu-forest-wide.webp` для ПК) сгенерированы специально для этой игры с помощью OpenAI Image Generation по оригинальным текстовым описаниям. Готовые PNG преобразованы в WebP с качеством 86 без изменения размеров. Иллюстрации не содержат сторонних загруженных изображений, текста или интерфейсных элементов.

## Устройство

- `src/levels.ts` — конфигурация пяти уровней: иллюстрация, число фрагментов, геометрия, стартовые позиции, название и фраза.
- `src/geometry.ts` — общая растровая маска с художественными профилями для 4, 6 и 8 деталей. Каждому пикселю соответствует ровно один фрагмент. Контролируются связность, площадь, ширина, вытянутость и острота формы.
- `src/layout.ts` — пропорциональная картина и стартовые позиции на телефоне, планшете и ПК.
- `src/progress.ts` — сохранение версии 1 в `localStorage`: пройденные уровни и последний выбранный уровень. Открытие уровней, три декоративные звезды и доступность картин в галерее выводятся из этого сохранения. Повреждённая запись сбрасывается безопасно. При недоступном хранилище игра остаётся рабочей, но прогресс не переживает перезагрузку.
- `src/main.ts` — меню, выбор уровней, галерея, общая игровая механика, подсказка, магнит, звук и завершение.
- `tools/generator.html` — локальная утилита для экспорта PNG атласа и JSON с координатами и метриками формы. Открывается через Vite по `/tools/generator.html`.
- `docs/screenshots/task4/` — реальные снимки этой версии в Chromium. Старое меню для сравнения находится в `docs/screenshots/01-menu-390x844.png` и `docs/screenshots/05-game-start-360x640.png`.

Игра загружает все пять изображений при запуске и затем работает без сети. Рекламы, экономики и авторизации Яндекса в этой версии нет. Уровни после пятого пока не созданы.
