# Мистические пазлы

Мобильная HTML5 игра на Phaser 3, TypeScript и Vite. Первый уровень собирает исходную иллюстрацию ночного дома у озера из восьми крупных фигурных фрагментов. Детали свободно перетаскиваются в основной игровой области, примагничиваются к своему месту, а после установки последней плавно уступают место цельной картине без швов. Переход выполняется только кнопкой.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Устройство

- `src/geometry.ts` — настроенная мозаика из восьми областей: неровное расположение центров, широкие изгибы и сглаженные общие границы. Каждый пиксель принадлежит ровно одному фрагменту. Проверяются связность, площадь, локальная ширина, вытянутость и острота выступов. Для других размеров есть экспериментальный генератор.
- `src/layout.ts` — размеры картины и асимметричная стартовая композиция для телефона, планшета и ПК.
- `src/main.ts` — меню, HUD, перетаскивание, подсказка, магнит, звук и завершение.
- `public/assets/moonlit-cottage.png` — исходная иллюстрация без обрезки и искажения пропорций.
- `tools/generator.html` — локальная утилита для экспорта PNG атласа и JSON с координатами и метриками формы. Открывается через Vite по `/tools/generator.html`.
- `docs/screenshots/` — реальные кадры Chromium после переработки; `docs/screenshots/before-polish/` — кадры до этой художественной полировки, `docs/screenshots/before/` — кадры самого первого прототипа.

Шаблон первого уровня специально настроен для иллюстрации 2:3. В утилите значения 2 × 4 выбирают этот восьмичастный художественный профиль, а не прямоугольную сетку; `seed` применяется только к экспериментальным конфигурациям. Для будущих уровней потребуется отдельная художественная проверка каждой картины и её раскладки. Новых уровней, экономики и рекламы здесь нет.
