# Мистические пазлы

Мобильный HTML5-прототип на Phaser 3, TypeScript и Vite. Сейчас в игре один уровень и одна оригинальная иллюстрация: дом у озера ночью. Восемь кусочков создаются из картины при запуске уровня, свободно перетаскиваются по общему полю и примагничиваются к своим координатам. После установки последнего фрагмента игра плавно показывает цельное исходное изображение.

## Запуск

```sh
npm install
npm run dev
```

Сборка и проверки:

```sh
npm test
npm run build
```

## Структура

- `src/main.ts` — сцены, интерфейс, перетаскивание, магнит и завершение.
- `src/geometry.ts` — воспроизводимая генерация нерегулярных областей с seed.
- `src/puzzleRules.ts` — правила перемещения, фиксации, завершения и ручного перехода.
- `public/assets/moonlit-cottage.png` — исходная иллюстрация уровня.
- `tools/generator.html` — локальная утилита для создания PNG атласа и JSON из своей иллюстрации.
- `docs/screenshots/` — кадры из работающей игры в Chromium.

Генератор запускается через Vite: откройте `/tools/generator.html`, выберите PNG/JPEG/WebP, настройте строки, столбцы и seed, затем сохраните PNG и JSON. Маски используют seed-ированный вариант диаграммы Вороного с мягко изменёнными границами; каждая точка исходной картины назначается ровно одному фрагменту.

Для следующего этапа можно вынести список картин и конфигурации фрагментов в данные уровней, добавить пять тестовых сцен, затем подключить сохранение прогресса и выбор собранной картины. SDK Яндекс Игр, реклама и экономика в прототип не включены.
