# Audio provenance

The five `.ogg` and five `.m4a` files here are original assets made for Mystic Puzzles by `tools/generate-audio.py`. The 40-second "moonlit-forest" loop and four effects are synthesized from mathematical waveforms. No third-party recording, sample, soundfont, or song is used. The project owner may distribute, modify, and monetize these audio files with the game without attribution or a third-party license obligation. Ogg Vorbis is preferred where supported; AAC/M4A provides Safari compatibility.
