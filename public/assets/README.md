# Художественные ассеты интерфейса

Картины уровней 1–5 получены из предоставленного архива `levels_01-05.zip` и преобразованы из PNG в WebP. Архив содержал только номера файлов, без названий картин. Прежние картины этих уровней сохранены в `docs/art/task24/legacy-assets/` и не входят в сборку игры.

| Файл | Назначение |
| --- | --- |
| `menu-storybook.webp` | Портретный пейзаж главного меню для телефона |
| `menu-storybook-wide.webp` | Панорамный пейзаж главного меню для ПК |
| `game-endpaper.webp` | Тёмный лесной фон вокруг игрового поля |
| `plaque-gold.webp` | Художественная основная кнопка меню |
| `plaque-navy.webp` | Второстепенные кнопки меню |
| `header-ornate.webp` | Тонкая игровая панель с орнаментом |
| `enchanted-library.webp` | Иллюстрация экспериментального шестого уровня, создана OpenAI Image Generation для этого проекта |
| `level-01.webp` … `level-05.webp` | Полноразмерные новые картины уровней 1–5; загружаются при открытии уровня или подробного просмотра галереи |
| `level-01-thumb.webp` … `level-06-thumb.webp` | Малые изображения для выбора уровней и галереи |

Текст, иконки и области нажатия рисуются отдельно в игре. Элементы не содержат текста или новой игровой механики.
