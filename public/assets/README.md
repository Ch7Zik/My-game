# Художественные ассеты интерфейса

Картины уровней 1–25 получены из предоставленных архивов `levels_01-05.zip` … `levels_21-25.zip`. Их сохранённые исходные PNG и JPG находятся в `docs/art/source/levels-01-05/` … `docs/art/source/levels-21-25/`, вне production-сборки. Старые картины 1–5 находятся в `docs/art/task24/legacy-assets/`, прежняя картина уровня 6 — в `docs/art/legacy-assets/`.

| Файл | Назначение |
| --- | --- |
| `menu-storybook.webp` | Портретный пейзаж главного меню для телефона |
| `menu-storybook-wide.webp` | Панорамный пейзаж главного меню для ПК |
| `game-endpaper.webp` | Тёмный лесной фон вокруг игрового поля |
| `plaque-gold.webp` | Художественная основная кнопка меню |
| `plaque-navy.webp` | Второстепенные кнопки меню |
| `header-ornate.webp` | Тонкая игровая панель с орнаментом |
| `level-01.webp` … `level-25.webp` | Полноразмерные картины; загружаются при открытии уровня или подробного просмотра галереи. Все 25 кодированы в WebP без потерь пикселей |
| `level-01-thumb.webp` … `level-25-thumb.webp` | Пропорционально уменьшенные изображения полного кадра для выбора уровней и галереи |

Текст, иконки и области нажатия рисуются отдельно в игре. Элементы не содержат текста или новой игровой механики.
