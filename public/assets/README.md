# Художественные ассеты интерфейса

Картины уровней 1–5 получены из `levels_01-05.zip`, картины 6–10 — из `levels_06-10.zip`, картины 11–15 — из `levels_11-15.zip`. Исходные PNG уровней 6–15 без изменений сохранены в `docs/art/source/levels-06-10/` и `docs/art/source/levels-11-15/`. Старые картины 1–5 находятся в `docs/art/task24/legacy-assets/`, прежняя картина уровня 6 — в `docs/art/legacy-assets/`. Все эти файлы вне production-сборки.

| Файл | Назначение |
| --- | --- |
| `menu-storybook.webp` | Портретный пейзаж главного меню для телефона |
| `menu-storybook-wide.webp` | Панорамный пейзаж главного меню для ПК |
| `game-endpaper.webp` | Тёмный лесной фон вокруг игрового поля |
| `plaque-gold.webp` | Художественная основная кнопка меню |
| `plaque-navy.webp` | Второстепенные кнопки меню |
| `header-ornate.webp` | Тонкая игровая панель с орнаментом |
| `level-01.webp` … `level-15.webp` | Полноразмерные картины; загружаются при открытии уровня или подробного просмотра галереи. Уровни 6–15 кодированы в WebP без потерь пикселей |
| `level-01-thumb.webp` … `level-15-thumb.webp` | Пропорционально уменьшенные изображения полного кадра для выбора уровней и галереи |

Текст, иконки и области нажатия рисуются отдельно в игре. Элементы не содержат текста или новой игровой механики.
